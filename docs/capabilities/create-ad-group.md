# Яндекс Директ: Создать группу объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт группу объявлений в кампании с заданными регионами показа.

Техническое имя: `create_ad_group`

## Какую задачу решает

> Я хочу создать группу объявлений.

Создаёт группу объявлений в кампании с заданными регионами показа.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать группу объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `name` — **обязательно**. Название группы объявлений.
- `campaignId` — **обязательно**. Id родительской кампании.
- `regionIds` — **обязательно**. Id регионов показа, например [225] — Россия.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать группу объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
