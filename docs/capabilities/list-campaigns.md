# Яндекс Директ: Список кампаний — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список кампаний с необязательными фильтрами по id, типу, состоянию и статусу.

Техническое имя: `list_campaigns`

## Какую задачу решает

> Я хочу посмотреть кампаний.

Возвращает список кампаний с необязательными фильтрами по id, типу, состоянию и статусу.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список кампаний» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id кампаний.
- `types` — **необязательно**. Фильтр по типам кампаний.
- `states` — **необязательно**. Фильтр по состояниям кампаний.
- `statuses` — **необязательно**. Фильтр по статусам модерации.
- `fieldNames` — **необязательно**. Какие поля кампании вернуть.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по LimitedBy (limit тогда не ограничивает общий объём).

## Что вернёт

Возвращает список кампаний с необязательными фильтрами по id, типу, состоянию и статусу.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть кампаний в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Денежные поля (DailyBudget.Amount и Funds общего счёта — Sum, Balance, SumAvailableForTransfer, Spend) отдаются в валюте аккаунта.

Доступ также зависит от прав токена, квот и ограничений исходного API.
