# Яндекс Директ: Изображения объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список изображений из библиотеки изображений, ключ — хеш изображения.

Техническое имя: `get_ad_images`

## Какую задачу решает

> Я хочу получить список изображений из библиотеки изображений, ключ — хеш изображения.

Возвращает список изображений из библиотеки изображений, ключ — хеш изображения.

## Когда использовать

Используйте эту возможность, когда нужен результат «Изображения объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `hashes` — **необязательно**. Фильтр по хешам изображений.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи.

## Что вернёт

Возвращает список изображений из библиотеки изображений, ключ — хеш изображения.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить список изображений из библиотеки изображений, ключ — хеш изображения в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Новые изображения загружает upload_ad_image.

Доступ также зависит от прав токена, квот и ограничений исходного API.
