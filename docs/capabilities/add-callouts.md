# Яндекс Директ: Добавить уточнения — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт уточнения, до 25 символов каждое.

Техническое имя: `add_callouts`

## Какую задачу решает

> Я хочу добавить уточнения.

Создаёт уточнения, до 25 символов каждое.

## Когда использовать

Используйте эту возможность, когда нужен результат «Добавить уточнения» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `texts` — **обязательно**. Тексты уточнений, до 25 символов каждый.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Добавить уточнения в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Уточнения неизменяемы — чтобы поменять, нужно удалить и создать заново. Привязка к объявлениям — через сервис Ads.

Доступ также зависит от прав токена, квот и ограничений исходного API.
