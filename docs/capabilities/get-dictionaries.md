# Яндекс Директ: Справочники — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …).

Техническое имя: `get_dictionaries`

## Какую задачу решает

> Я хочу получить справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …).

Возвращает справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …).

## Когда использовать

Используйте эту возможность, когда нужен результат «Справочники» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `names` — **обязательно**. Названия нужных справочников.

## Что вернёт

Возвращает справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …).

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …) в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

GeoRegions может быть очень большим — для поиска регионов лучше get_regions.

Доступ также зависит от прав токена, квот и ограничений исходного API.
