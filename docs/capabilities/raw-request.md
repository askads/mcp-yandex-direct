# Яндекс Директ: Прямой вызов API Яндекс Директа — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Универсальный запрос: вызывает напрямую любой сервис или метод API Яндекс Директа (например service "bidmodifiers", method "get").

Техническое имя: `raw_request`

## Какую задачу решает

> Я хочу выполнить дополнительный запрос к API.

Универсальный запрос: вызывает напрямую любой сервис или метод API Яндекс Директа (например service "bidmodifiers", method "get").

## Когда использовать

Используйте эту возможность, когда нужен результат «Прямой вызов API Яндекс Директа» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `service` — **обязательно**. Путь сервиса строчными буквами, например campaigns, bidmodifiers, sitelinks, adextensions, changes, keywordsresearch.
- `method` — **обязательно**. Метод API, например get, add, update, delete, set, toggle, checkCampaigns.
- `params` — **необязательно**. Объект params для метода — как есть.
- `apiVersion` — **необязательно**. Версия API для этого запроса: v5 или v501. Если не указана — v5, а для campaigns и adgroups — v501: только она называет Единую перформанс-кампанию и её группы настоящими типами (UNIFIED_CAMPAIGN, UNIFIED_AD_GROUP) и фильтрует по ним, v5 выдаёт их за TEXT_CAMPAIGN и TEXT_AD_GROUP. В песочнице доступна только v5.
- `confirmWrite` — **необязательно**. Должен быть true для запуска метода записи (всё, кроме get/has/check).

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Прямой вызов API Яндекс Директа» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить дополнительный запрос к API в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Нужен для сервисов, у которых нет отдельного инструмента. Деньги — в микроединицах (без конвертации). Методы чтения (get/has/check) выполняются свободно; любой другой метод считается записью и требует confirmWrite=true.

Доступ также зависит от прав токена, квот и ограничений исходного API.

## Связанные MCP-инструменты

Связанных специализированных инструментов в этой группе нет.
