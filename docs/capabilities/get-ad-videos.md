# Яндекс Директ: Видео объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Читает видео из библиотеки видео по id (API требует id).

Техническое имя: `get_ad_videos`

## Какую задачу решает

> Я хочу посмотреть видео объявлений.

Читает видео из библиотеки видео по id (API требует id).

## Когда использовать

Используйте эту возможность, когда нужен результат «Видео объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id видео (обязательны по требованию API).
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть видео объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Загрузка идёт через raw_request (advideos/add).

Доступ также зависит от прав токена, квот и ограничений исходного API.
