# Яндекс Директ: Уточнения — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список уточнений из библиотеки adextensions.

Техническое имя: `get_callouts`

## Какую задачу решает

> Я хочу получить список уточнений из библиотеки adextensions.

Возвращает список уточнений из библиотеки adextensions.

## Когда использовать

Используйте эту возможность, когда нужен результат «Уточнения» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id уточнений.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи.

## Что вернёт

Возвращает список уточнений из библиотеки adextensions.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить список уточнений из библиотеки adextensions в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Привязать уточнение к объявлению можно через сервис Ads.

Доступ также зависит от прав токена, квот и ограничений исходного API.
