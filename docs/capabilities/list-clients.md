# Яндекс Директ: Клиенты и кабинеты в управлении — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Перечисляет рекламодателей, с которыми может работать подключённый токен: клиентов агентства и кабинеты в управлении.

Техническое имя: `list_clients`

## Какую задачу решает

> Я хочу увидеть клиентов агентства и кабинеты в управлении, чтобы работать с нужным из них прямо в диалоге.

Агентство получает список клиентов из `AgencyClients.get`: логин, название, валюту. Обычный аккаунт, который ведёт чужие кабинеты как представитель, получает логины из `YANDEX_DIRECT_CLIENTS`, потому что API Директа такие кабинеты не перечисляет. Логин из ответа передаётся в параметр `client_login` любого инструмента данных, и переключаться между клиентами можно без перезапуска сервера.

## Когда использовать

- Сразу после подключения агентского аккаунта: `finish_login` подскажет это сам.
- Когда список кампаний неожиданно пуст: агентский токен без клиента видит собственный аккаунт агентства.
- Когда пользователь называет клиента по имени, а не по логину: найдите его через `search`.

## Что нужно передать

- `search` — **необязательно**. Подстрока логина или названия клиента, без учёта регистра.
- `includeArchived` — **необязательно**. Показать и архивных клиентов агентства. По умолчанию — только активных.
- `limit` — **необязательно**. Сколько клиентов вернуть, 1–1000. По умолчанию 200.

## Что вернёт

- `accountType` — `agency` (токен агентства) или `advertiser` (обычный аккаунт).
- `total` — сколько клиентов подошло под фильтр.
- `clients` — `login`, `name`, `currency`, `archived` и `source`: `agency` из API или `config` из `YANDEX_DIRECT_CLIENTS`.
- `_truncated` — если показаны не все клиенты.
- `note` — у обычного аккаунта без настроенного списка: как его задать.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Покажи клиентов агентства, а потом список кампаний клиента «Магазин Питер».

## Возможные ошибки и ограничения

API не умеет перечислять кабинеты, где логин токена — представитель. Для такого аккаунта список есть только в `YANDEX_DIRECT_CLIENTS`. Любой доступный логин всё равно можно передать в `client_login` напрямую. Логин, к которому у токена нет доступа, вернёт ошибку 8800 при первом же вызове с ним. `AgencyClients.get` отдаёт до 10 000 клиентов за вызов, поэтому у очень крупного агентства список сужается через `search`.

Доступ также зависит от прав токена, квот и ограничений исходного API.
