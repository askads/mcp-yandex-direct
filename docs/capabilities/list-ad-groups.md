# Яндекс Директ: Список групп объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список групп объявлений.

Техническое имя: `list_ad_groups`

## Какую задачу решает

> Я хочу посмотреть групп объявлений.

Возвращает список групп объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список групп объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignIds` — **необязательно**. Фильтр по id кампаний.
- `ids` — **необязательно**. Фильтр по id групп объявлений.
- `fieldNames` — **необязательно**. Какие поля группы вернуть.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по LimitedBy (limit тогда не ограничивает общий объём).

## Что вернёт

Возвращает список групп объявлений.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть групп объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Нужно передать campaignIds и/или ids — API Яндекс Директа требует хотя бы один критерий отбора.

Доступ также зависит от прав токена, квот и ограничений исходного API.
