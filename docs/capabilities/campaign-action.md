# Яндекс Директ: Действие с кампаниями — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Выполняет действие над кампаниями по id: suspend, resume, archive, unarchive или delete.

Техническое имя: `campaign_action`

## Какую задачу решает

> Я хочу выполнить действие с кампаниями.

Выполняет действие над кампаниями по id: suspend, resume, archive, unarchive или delete.

## Когда использовать

Используйте эту возможность, когда нужен результат «Действие с кампаниями» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `action` — **обязательно**. Действие из перечня, указанного в описании инструмента.
- `ids` — **обязательно**. Id кампаний, к которым применить действие.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Действие с кампаниями» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить действие с кампаниями в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
