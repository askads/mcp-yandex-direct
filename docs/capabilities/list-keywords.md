# Яндекс Директ: Список ключевых фраз — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список ключевых фраз с фильтром по кампании, группе объявлений или id.

Техническое имя: `list_keywords`

## Какую задачу решает

> Я хочу посмотреть ключевых фраз.

Возвращает список ключевых фраз с фильтром по кампании, группе объявлений или id.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список ключевых фраз» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignIds` — **необязательно**. Фильтр по id кампаний.
- `adGroupIds` — **необязательно**. Фильтр по id групп объявлений.
- `ids` — **необязательно**. Фильтр по id ключевых фраз.
- `fieldNames` — **необязательно**. Какие поля ключевой фразы вернуть.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по LimitedBy (limit тогда не ограничивает общий объём).

## Что вернёт

Возвращает список ключевых фраз с фильтром по кампании, группе объявлений или id.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть ключевых фраз в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Bid и ContextBid отдаются в валюте аккаунта.

Доступ также зависит от прав токена, квот и ограничений исходного API.
