# Яндекс Директ: Корректировки ставок — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Читает корректировки ставок (мобильные, десктоп, демография, ретаргетинг, регионы, видео) для кампаний или групп объявлений.

Техническое имя: `get_bid_modifiers`

## Какую задачу решает

> Я хочу посмотреть корректировки ставок.

Читает корректировки ставок (мобильные, десктоп, демография, ретаргетинг, регионы, видео) для кампаний или групп объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Корректировки ставок» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignIds` — **необязательно**. Фильтр по id кампаний.
- `adGroupIds` — **необязательно**. Фильтр по id групп объявлений.
- `ids` — **необязательно**. Фильтр по id корректировок.
- `types` — **необязательно**. Фильтр по типам корректировок.
- `levels` — **необязательно**. Уровни, на которых читать. По умолчанию оба: CAMPAIGN и AD_GROUP.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть корректировки ставок в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

BidModifier — это процент, а не деньги.

Доступ также зависит от прав токена, квот и ограничений исходного API.
