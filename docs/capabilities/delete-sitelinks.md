# Яндекс Директ: Удалить наборы быстрых ссылок — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Удаляет наборы быстрых ссылок по id (удалить можно только наборы, не привязанные ни к одному объявлению).

Техническое имя: `delete_sitelinks`

## Какую задачу решает

> Я хочу удалить наборы быстрых ссылок.

Удаляет наборы быстрых ссылок по id (удалить можно только наборы, не привязанные ни к одному объявлению).

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить наборы быстрых ссылок» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id наборов, которые нужно удалить.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Удалить наборы быстрых ссылок» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить наборы быстрых ссылок в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
