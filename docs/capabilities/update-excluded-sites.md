# Яндекс Директ: Изменить запрещённые площадки — MCP-инструмент (tool)

**MCP-инструмент (tool) для запрещённых площадок Яндекс Директа:** Дописывает, убирает, заменяет или очищает список площадок РСЯ, на которых кампании запрещено показываться.

Техническое имя: `update_excluded_sites`

## Какую задачу решает

> Я хочу отключить площадку, которая тратит бюджет без заявок, и не потерять уже запрещённые.

API Яндекс Директа хранит запрещённые площадки одним списком и при записи заменяет его целиком. Инструмент делает действие явным: дописать, убрать, заменить или очистить.

## Когда использовать

После отчёта по площадкам (`get_statistics` с разрезом `Placement`), когда сайт, приложение или внешняя сеть расходует бюджет без конверсий. Площадки запрещаются только в сетях: на поиске это не работает.

## Что нужно передать

- `campaignId` — **обязательно**. Id кампании.
- `action` — **обязательно**:
  - `add` — дописать площадки к текущим. Инструмент читает текущий список и записывает объединённый: два вызова API.
  - `remove` — вернуть показы на указанных площадках. Тоже чтение и запись.
  - `replace` — записать ровно переданный список вместо текущего, без чтения. Пустой список не принимается.
  - `clear` — снять все запреты.
- `sites` — нужен для `add`, `remove` и `replace`, не передаётся для `clear`:
  - домен без протокола: `example.com` (API сам уберёт `www.` и приведёт к нижнему регистру);
  - id приложения: `com.example.app` (числовой id App Store вида `id123456789` API отвергает);
  - название внешней сети из `get_dictionaries` → `SupplySidePlatforms`, например `BidSwitch`.

## Что вернёт

JSON с итогом: `before` и `after` — число площадок до и после; для `add` — `added` и `alreadyPresent`, для `remove` — `removed` и `notFound`; `changed` — была ли запись. Рядом лежит `UpdateResults` из API.

## Что изменится в Яндекс Директе

Список запрещённых площадок кампании. `replace`, `remove` и `clear` снимают запреты, отката нет, поэтому инструмент помечен как опасный. Если `add` или `remove` ничего не меняют, записи нет.

## Пример запроса

> Посмотри площадки РСЯ кампании 712108518 за 30 дней и запрети те, где расход больше 500 ₽ и ноль конверсий. Сначала покажи список.

## Возможные ошибки и ограничения

- До 1000 площадок на кампанию, до 255 символов в каждой.
- Площадка с протоколом (`https://…`) отклоняется до вызова API.
- Между чтением и записью нет блокировки: правка того же списка в интерфейсе в эту секунду будет перезаписана.

Доступ также зависит от прав токена, квот и ограничений исходного API.
