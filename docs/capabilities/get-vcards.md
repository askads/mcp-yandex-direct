# Яндекс Директ: Визитки — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Читает виртуальные визитки по id.

Техническое имя: `get_vcards`

## Какую задачу решает

> Я хочу посмотреть визитки объявлений.

Читает виртуальные визитки по id.

## Когда использовать

Используйте эту возможность, когда нужен результат «Визитки» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id визиток (обязательны по требованию API).
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Посмотреть визитки объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

API требует id — их можно взять из поля VCardId объявлений.

Доступ также зависит от прав токена, квот и ограничений исходного API.
