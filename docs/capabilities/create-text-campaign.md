# Яндекс Директ: Создать текстовую кампанию — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт кампанию TextCampaign (текстово-графические объявления).

Техническое имя: `create_text_campaign`

## Какую задачу решает

> Я хочу создать текстовую кампанию.

Создаёт кампанию TextCampaign (текстово-графические объявления).

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать текстовую кампанию» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `name` — **обязательно**. Название кампании.
- `startDate` — **обязательно**. Дата начала в формате YYYY-MM-DD.
- `endDate` — **необязательно**. Дата окончания в формате YYYY-MM-DD.
- `dailyBudgetAmount` — **необязательно**. Дневной бюджет в валюте аккаунта (конвертируется в микроединицы).
- `dailyBudgetMode` — **необязательно**. Режим траты дневного бюджета: STANDARD — показы как можно быстрее, DISTRIBUTED — равномерно в течение дня. По умолчанию STANDARD.
- `biddingStrategy` — **необязательно**. Полный объект BiddingStrategy {Search, Network}. Заменяет значение по умолчанию.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать текстовую кампанию в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Без biddingStrategy применяются ручные ставки на поиске с отключёнными сетями (Search HIGHEST_POSITION, Network SERVING_OFF); чтобы включить автостратегию или сети, передать biddingStrategy целиком — {Search, Network}.

Доступ также зависит от прав токена, квот и ограничений исходного API.
