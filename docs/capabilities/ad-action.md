# Яндекс Директ: Действие с объявлениями — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Выполняет действие над объявлениями по id: moderate, suspend, resume, archive, unarchive или delete.

Техническое имя: `ad_action`

## Какую задачу решает

> Я хочу выполнить действие с объявлениями.

Выполняет действие над объявлениями по id: moderate, suspend, resume, archive, unarchive или delete.

## Когда использовать

Используйте эту возможность, когда нужен результат «Действие с объявлениями» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `action` — **обязательно**. Действие из перечня, указанного в описании инструмента.
- `ids` — **обязательно**. Id объявлений, к которым применить действие.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Действие с объявлениями» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Выполнить действие с объявлениями в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
