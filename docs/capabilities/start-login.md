# Яндекс Директ: Начать подключение — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Начинает подключение рекламного кабинета прямо в диалоге — возвращает ссылку на страницу Яндекс OAuth, не требуя правки конфигурации.

Техническое имя: `start_login`

## Какую задачу решает

> Я хочу подключить Яндекс Директ прямо из диалога, без правки конфигурации и перезапуска клиента.

Первый шаг входа: инструмент формирует ссылку на страницу авторизации Яндекса (с защитой PKCE) и запоминает секретную часть у себя в процессе. Пользователь открывает ссылку, входит под аккаунтом с доступом к нужному рекламному кабинету, подтверждает доступ и получает код подтверждения.

## Когда использовать

Используйте эту возможность, когда сервер не подключён (инструменты данных отвечают ошибкой подключения) или когда нужно войти под другим аккаунтом Яндекса. Повторный вызов заменяет предыдущую незавершённую попытку входа.

## Что нужно передать

Параметры не нужны.

## Что вернёт

`authorizeUrl` — ссылку, которую нужно показать пользователю целиком, `clientId` OAuth-приложения, срок действия кода (10 минут) и подсказку о следующем шаге: дождаться код подтверждения и передать его в `finish_login`.

## Что изменится в Яндекс Директе

В рекламном кабинете ничего не меняется. Инструмент лишь готовит вход: в сеть ничего не отправляется, запоминается только локальная пара PKCE для будущего обмена кода.

## Пример запроса

> Подключи Яндекс Директ — дай ссылку для входа.

## Возможные ошибки и ограничения

Код подтверждения живёт 10 минут и одноразовый: если пользователь не успел, вызовите `start_login` заново. Сам по себе код бесполезен для постороннего — обменять его на токен может только этот сервер, у которого хранится секретная часть PKCE.
