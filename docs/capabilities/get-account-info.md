# Яндекс Директ: Данные аккаунта — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа.

Техническое имя: `get_account_info`

## Какую задачу решает

> Я хочу получить данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа.

Возвращает данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа.

## Когда использовать

Используйте эту возможность, когда нужен результат «Данные аккаунта» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `fieldNames` — **необязательно**. Какие поля клиента вернуть. По умолчанию — типовой набор.

## Что вернёт

Возвращает данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.
