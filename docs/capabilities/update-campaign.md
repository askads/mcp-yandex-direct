# Яндекс Директ: Обновить кампанию — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Обновляет название, дату окончания и/или минус-фразы кампании (campaigns/update).

Техническое имя: `update_campaign`

## Какую задачу решает

> Я хочу обновить кампанию.

Обновляет название, дату окончания и/или минус-фразы кампании (campaigns/update). Бюджет здесь не меняется: у Директа он недельный и является частью стратегии — [`set_campaign_strategy`](./set-campaign-strategy.md).

## Когда использовать

Используйте эту возможность, когда нужен результат «Обновить кампанию» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `id` — **обязательно**. Id кампании, которую нужно обновить.
- `name` — **необязательно**. Новое название кампании.
- `endDate` — **необязательно**. Новая дата окончания в формате YYYY-MM-DD.
- `negativeKeywords` — **необязательно**. Заменяет минус-фразы кампании; пустой массив очищает их. Чтобы дописать или убрать отдельные фразы, не затирая список, — update_negative_keywords.
- `dailyBudgetAmount`, `dailyBudgetMode` — **устарело**. Дневного бюджета в Директе больше нет (с 30.11.2026); вызов с любым из них отклоняется до запроса с подсказкой про `set_campaign_strategy`. Параметры оставлены в схеме намеренно: иначе клиент с закешированным списком инструментов передал бы их, SDK молча отбросил бы, и кампания была бы переименована без смены бюджета при ответе «успех».

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Обновить кампанию в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Запрос идёт в API v501, в песочнице — в v5.

Бюджет этим инструментом не задаётся. Дневного бюджета (`DailyBudget`) у Директа больше нет (с 30.11.2026): бюджет недельный и живёт в стратегии — у автостратегий `WeeklySpendLimit` в их структуре параметров, у ручных ставок ЕПК `HighestPosition: {WeeklySpendLimit}` (у ручных ставок текстовой кампании бюджета нет); менять его — `set_campaign_strategy`.

Доступ также зависит от прав токена, квот и ограничений исходного API.
