# Яндекс Директ: Обновить кампанию — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Обновляет название, дату окончания и/или дневной бюджет кампании (campaigns/update).

Техническое имя: `update_campaign`

## Какую задачу решает

> Я хочу обновить кампанию.

Обновляет название, дату окончания и/или дневной бюджет кампании (campaigns/update).

## Когда использовать

Используйте эту возможность, когда нужен результат «Обновить кампанию» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `id` — **обязательно**. Id кампании, которую нужно обновить.
- `name` — **необязательно**. Новое название кампании.
- `endDate` — **необязательно**. Новая дата окончания в формате YYYY-MM-DD.
- `dailyBudgetAmount` — **необязательно**. Дневной бюджет в валюте аккаунта.
- `dailyBudgetMode` — **необязательно**. Режим траты дневного бюджета: STANDARD — показы как можно быстрее, DISTRIBUTED — равномерно в течение дня. Если не задан, сохраняется текущий режим кампании.
- `negativeKeywords` — **необязательно**. Заменяет минус-фразы кампании; пустой массив очищает их.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Обновить кампанию в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

API требует передавать режим бюджета (Mode) вместе с суммой, поэтому если dailyBudgetMode не задан, текущий режим кампании дочитывается через campaigns/get и сохраняется — смена суммы не меняет темп открутки.

Доступ также зависит от прав токена, квот и ограничений исходного API.
