# Яндекс Директ: Удалить группы объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Удаляет группы объявлений по id (adgroups/delete).

Техническое имя: `delete_ad_groups`

## Какую задачу решает

> Я хочу удалить группы объявлений.

Удаляет группы объявлений по id (adgroups/delete).

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить группы объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id групп, которые нужно удалить.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Удалить группы объявлений» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить группы объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Вместе с группой удаляются её объявления и ключевые фразы; отменить это нельзя.

Доступ также зависит от прав токена, квот и ограничений исходного API.
