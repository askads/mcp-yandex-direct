# Яндекс Директ: Добавить корректировку ставок — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Добавляет корректировку ставок на кампанию или группу объявлений.

Техническое имя: `add_bid_modifier`

## Какую задачу решает

> Я хочу добавить корректировку ставок.

Добавляет корректировку ставок на кампанию или группу объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Добавить корректировку ставок» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignId` — **необязательно**. Id кампании (либо это поле, либо adGroupId).
- `adGroupId` — **необязательно**. Id группы объявлений (либо это поле, либо campaignId).
- `mobile` — **необязательно**. Корректировка для мобильных.
- `desktop` — **необязательно**. Корректировка для десктопа.
- `demographics` — **необязательно**. Корректировки по демографии.
- `retargeting` — **необязательно**. Корректировки по ретаргетингу.
- `regional` — **необязательно**. Корректировки по регионам.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Добавить корректировку ставок в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Значения BidModifier — проценты по правилам API (например, 0–1300), а не деньги.

Доступ также зависит от прав токена, квот и ограничений исходного API.
