# Яндекс Директ: Создать текстовое объявление — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт текстовое объявление (TextAd) в группе объявлений.

Техническое имя: `create_text_ad`

## Какую задачу решает

> Я хочу создать текстовое объявление.

Создаёт текстовое объявление (TextAd) в группе объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать текстовое объявление» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `adGroupId` — **обязательно**. Id родительской группы объявлений.
- `title` — **обязательно**. Заголовок (Title 1), до 56 символов.
- `title2` — **необязательно**. Второй заголовок (Title 2), до 30 символов.
- `text` — **обязательно**. Текст объявления, до 81 символа.
- `href` — **обязательно**. URL посадочной страницы (обязателен для TextAdAdd).
- `mobile` — **необязательно**. Мобильное ли это объявление. Поле в API устарело (значение принудительно NO), но остаётся обязательным.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать текстовое объявление в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Новые объявления создаются черновиками. TextAdAdd требует хотя бы одно из Href/TurboPageId/VCardId/BusinessId — этот инструмент передаёт посадочную страницу через href (обязателен); объявление с BusinessId вместо ссылки создаётся через raw_request.

Доступ также зависит от прав токена, квот и ограничений исходного API.
