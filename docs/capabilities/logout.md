# Яндекс Директ: Отключить Директ — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Отключает сервер от рекламного кабинета — удаляет сохранённый токен доступа с диска.

Техническое имя: `logout`

## Какую задачу решает

> Я хочу отключить Яндекс Директ и убрать сохранённый токен с этого компьютера.

Удаляет файл с токеном, сохранённым входом через диалог. После этого инструменты данных снова отвечают, что подключение не настроено, пока не выполнен новый вход.

## Когда использовать

Используйте эту возможность, когда нужно сменить аккаунт, передать компьютер другому человеку или просто разорвать подключение. Токен, заданный переменной окружения `YANDEX_DIRECT_TOKEN`, инструмент не трогает — его убирают из конфигурации MCP-клиента вручную.

## Что нужно передать

Параметры не нужны.

## Что вернёт

`removed` — был ли на диске сохранённый токен, поясняющую заметку и признак `envTokenStillSet`: если токен задан переменной окружения, сервер останется подключённым через неё.

## Что изменится в Яндекс Директе

В рекламном кабинете ничего не меняется. С локального диска безвозвратно удаляется файл `credentials.json`; доступ, выданный приложению, остаётся активным на стороне Яндекса — отозвать его можно в Яндекс ID.

## Пример запроса

> Отключи Яндекс Директ на этом компьютере.

## Возможные ошибки и ограничения

Удаление файла необратимо: для нового подключения придётся пройти `start_login` заново. Полный отзыв доступа выполняется не здесь, а в настройках безопасности Яндекс ID.
