# MCP-возможности Яндекс Директа

Каталог содержит 44 публичные страницы — по одной для каждого зарегистрированного MCP-инструмента (tool) репозитория `mcp-yandex-direct`. Страницы начинаются с задачи пользователя, объясняют результат и отдельно показывают, изменит ли вызов реальные данные.

Используйте этот каталог для выбора готовой возможности. Полные схемы параметров и ответы API остаются в [техническом справочнике](../TOOLS.md).

## Подключение

- [Статус подключения](./auth-status.md) — Показывает, подключён ли Яндекс Директ: есть ли токен, откуда он взят и когда истекает. Ничего не отправляет в сеть и не показывает сам токен. **Воздействие:** только чтение.
- [Начать подключение](./start-login.md) — Первый шаг подключения из диалога: возвращает ссылку на страницу Яндекс OAuth, которую нужно показать пользователю. **Воздействие:** только чтение.
- [Завершить подключение](./finish-login.md) — Второй шаг: обменивает код подтверждения на токен доступа и сохраняет его в файл только для владельца. **Воздействие:** изменяет данные.
- [Отключить Директ](./logout.md) — Удаляет сохранённый токен Директа с диска; переменную окружения не трогает. **Воздействие:** опасная операция.

## Объявления

- [Действие с объявлениями](./ad-action.md) — Выполняет действие над объявлениями по id: moderate, suspend, resume, archive, unarchive или delete. **Воздействие:** опасная операция.
- [Создать текстовое объявление](./create-text-ad.md) — Создаёт текстовое объявление (TextAd) в группе объявлений. **Воздействие:** изменяет данные.
- [Список объявлений](./list-ads.md) — Возвращает список объявлений с необязательными фильтрами по кампании, группе, id, состоянию и статусу. **Воздействие:** только чтение.
- [Обновить текстовое объявление](./update-text-ad.md) — Обновляет заголовок, текст или посадочную страницу текстового объявления (ads/update). **Воздействие:** изменяет данные.

## Корректировки ставок

- [Добавить корректировку ставок](./add-bid-modifier.md) — Добавляет корректировку ставок на кампанию или группу объявлений. **Воздействие:** изменяет данные.
- [Удалить корректировки ставок](./delete-bid-modifiers.md) — Удаляет корректировки ставок по id (bidmodifiers/delete). **Воздействие:** опасная операция.
- [Корректировки ставок](./get-bid-modifiers.md) — Читает корректировки ставок (мобильные, десктоп, демография, ретаргетинг, регионы, видео) для кампаний или групп объявлений. **Воздействие:** только чтение.
- [Изменить корректировки ставок](./set-bid-modifiers.md) — Меняет процент существующих корректировок (bidmodifiers/set) по id корректировки. **Воздействие:** изменяет данные.

## Расширения объявлений

- [Добавить уточнения](./add-callouts.md) — Создаёт уточнения, до 25 символов каждое. **Воздействие:** изменяет данные.
- [Создать набор быстрых ссылок](./create-sitelinks-set.md) — Создаёт набор быстрых ссылок (1–8 штук). **Воздействие:** изменяет данные.
- [Создать визитку](./create-vcard.md) — Создаёт виртуальную визитку в кампании. **Воздействие:** изменяет данные.
- [Удалить уточнения](./delete-callouts.md) — Удаляет уточнения по id (adextensions/delete). **Воздействие:** опасная операция.
- [Удалить наборы быстрых ссылок](./delete-sitelinks.md) — Удаляет наборы быстрых ссылок по id (удалить можно только наборы, не привязанные ни к одному объявлению). **Воздействие:** опасная операция.
- [Удалить визитки](./delete-vcards.md) — Удаляет визитки по id (vcards/delete). **Воздействие:** опасная операция.
- [Уточнения](./get-callouts.md) — Возвращает список уточнений из библиотеки adextensions. **Воздействие:** только чтение.
- [Наборы быстрых ссылок](./get-sitelinks.md) — Читает наборы быстрых ссылок по id. **Воздействие:** только чтение.
- [Визитки](./get-vcards.md) — Читает виртуальные визитки по id. **Воздействие:** только чтение.

## Ключевые фразы и ставки

- [Добавить ключевые фразы](./add-keywords.md) — Добавляет ключевые фразы в группу объявлений, при необходимости — со ставками для поиска и сетей. **Воздействие:** изменяет данные.
- [Действие с ключевыми фразами](./keyword-action.md) — Выполняет действие над ключевыми фразами по id: suspend, resume или delete. **Воздействие:** опасная операция.
- [Список ключевых фраз](./list-keywords.md) — Возвращает список ключевых фраз с фильтром по кампании, группе объявлений или id. **Воздействие:** только чтение.
- [Задать ставки ключевых фраз](./set-keyword-bids.md) — Задаёт ручные ставки на поиске и в сетях для ключевых фраз либо для всех фраз указанных групп объявлений или кампаний (keywordbids/set). **Воздействие:** изменяет данные.

## Кампании

- [Действие с кампаниями](./campaign-action.md) — Выполняет действие над кампаниями по id: suspend, resume, archive, unarchive или delete. **Воздействие:** опасная операция.
- [Создать текстовую кампанию](./create-text-campaign.md) — Создаёт кампанию TextCampaign (текстово-графические объявления). **Воздействие:** изменяет данные.
- [Список кампаний](./list-campaigns.md) — Возвращает список кампаний с необязательными фильтрами по id, типу, состоянию и статусу. **Воздействие:** только чтение.
- [Обновить кампанию](./update-campaign.md) — Обновляет название, дату окончания и/или дневной бюджет кампании (campaigns/update). **Воздействие:** изменяет данные.

## Группы объявлений

- [Создать группу объявлений](./create-ad-group.md) — Создаёт группу объявлений в кампании с заданными регионами показа. **Воздействие:** изменяет данные.
- [Удалить группы объявлений](./delete-ad-groups.md) — Удаляет группы объявлений по id (adgroups/delete). **Воздействие:** опасная операция.
- [Список групп объявлений](./list-ad-groups.md) — Возвращает список групп объявлений. **Воздействие:** только чтение.
- [Обновить группу объявлений](./update-ad-group.md) — Обновляет название и/или регионы показа группы объявлений (adgroups/update). **Воздействие:** изменяет данные.

## Аккаунт

- [Данные аккаунта](./get-account-info.md) — Возвращает данные текущего аккаунта рекламодателя (логин, валюта, тип, страна) через сервис `clients` Яндекс Директа. **Воздействие:** только чтение.
- [Баланс аккаунта](./get-balance.md) — Возвращает баланс общего счёта и финансовые поля (Amount, AmountAvailableForTransfer, Currency, Discount, AccountID) через устаревший сервис AccountManagement Live v4 — единственный API Яндекс Директа, который отдаёт баланс (в v5 финансового метода нет). **Воздействие:** только чтение.
- [Квота API](./get-quota.md) — Возвращает сегодняшнюю квоту баллов API (потрачено / осталось / лимит) из заголовка Units — чтобы не упереться в дневной лимит. **Воздействие:** только чтение.

## Медиа

- [Изображения объявлений](./get-ad-images.md) — Возвращает список изображений из библиотеки изображений, ключ — хеш изображения. **Воздействие:** только чтение.
- [Видео объявлений](./get-ad-videos.md) — Читает видео из библиотеки видео по id (API требует id). **Воздействие:** только чтение.
- [Креативы](./get-creatives.md) — Возвращает список креативов (смарт-баннеры, HTML5) из библиотеки креативов. **Воздействие:** только чтение.
- [Загрузить изображение](./upload-ad-image.md) — Загружает изображение в библиотеку изображений (adimages/add) и возвращает его AdImageHash — этот хеш подставляется в поле AdImageHash текстово-графического объявления. **Воздействие:** изменяет данные.

## Справочники

- [Справочники](./get-dictionaries.md) — Возвращает справочники Яндекс Директа (валюты, часовые пояса, константы, категории объявлений, …). **Воздействие:** только чтение.
- [Поиск регионов](./get-regions.md) — Ищет id регионов для таргетинга (те самые regionIds, которые нужны create_ad_group). **Воздействие:** только чтение.

## Статистика

- [Статистика](./get-statistics.md) — Запрашивает отчёт по эффективности через сервис Reports Яндекс Директа. **Воздействие:** только чтение.

## Дополнительные методы API

- [Прямой вызов API Яндекс Директа](./raw-request.md) — Универсальный запрос: вызывает напрямую любой сервис или метод API Яндекс Директа v5 (например service "bidmodifiers", method "get"). **Воздействие:** опасная операция.
