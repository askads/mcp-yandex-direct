# Яндекс Директ: Удалить уточнения — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Удаляет уточнения по id (adextensions/delete).

Техническое имя: `delete_callouts`

## Какую задачу решает

> Я хочу удалить уточнения.

Удаляет уточнения по id (adextensions/delete).

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить уточнения» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id уточнений, которые нужно удалить.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Удалить уточнения» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить уточнения в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
