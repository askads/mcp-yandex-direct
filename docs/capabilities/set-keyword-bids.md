# Яндекс Директ: Задать ставки ключевых фраз — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Задаёт ручные ставки на поиске и в сетях для ключевых фраз либо для всех фраз указанных групп объявлений или кампаний (keywordbids/set).

Техническое имя: `set_keyword_bids`

## Какую задачу решает

> Я хочу задать ставки ключевых фраз.

Задаёт ручные ставки на поиске и в сетях для ключевых фраз либо для всех фраз указанных групп объявлений или кампаний (keywordbids/set).

## Когда использовать

Используйте эту возможность, когда нужен результат «Задать ставки ключевых фраз» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `bids` — **обязательно**. В каждом элементе нужен один целевой id и хотя бы одно из полей bid/contextBid.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Задать ставки ключевых фраз в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Ставки — в валюте аккаунта.

Доступ также зависит от прав токена, квот и ограничений исходного API.
