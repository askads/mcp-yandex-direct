# Яндекс Директ: Добавить ключевые фразы — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Добавляет ключевые фразы в группу объявлений, при необходимости — со ставками для поиска и сетей.

Техническое имя: `add_keywords`

## Какую задачу решает

> Я хочу добавить ключевые фразы.

Добавляет ключевые фразы в группу объявлений, при необходимости — со ставками для поиска и сетей.

## Когда использовать

Используйте эту возможность, когда нужен результат «Добавить ключевые фразы» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `adGroupId` — **обязательно**. Id группы объявлений.
- `keywords` — **обязательно**. Ключевые фразы для добавления.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Добавить ключевые фразы в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
