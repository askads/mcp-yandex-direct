# Яндекс Директ: Удалить визитки — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Удаляет визитки по id (vcards/delete).

Техническое имя: `delete_vcards`

## Какую задачу решает

> Я хочу удалить визитки.

Удаляет визитки по id (vcards/delete).

## Когда использовать

Используйте эту возможность, когда нужен результат «Удалить визитки» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **обязательно**. Id визиток, которые нужно удалить.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Исходный код помечает весь вызов «Удалить визитки» как опасный. Конкретное воздействие зависит от переданного действия и описано ниже; перед вызовом проверьте параметры и обратимость результата.

## Пример запроса

> Удалить визитки в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их. Сначала покажи, какие данные изменятся, и дождись подтверждения.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
