# Яндекс Директ: Креативы — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список креативов (смарт-баннеры, HTML5) из библиотеки креативов.

Техническое имя: `get_creatives`

## Какую задачу решает

> Я хочу получить список креативов (смарт-баннеры, HTML5) из библиотеки креативов.

Возвращает список креативов (смарт-баннеры, HTML5) из библиотеки креативов.

## Когда использовать

Используйте эту возможность, когда нужен результат «Креативы» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `ids` — **необязательно**. Фильтр по id креативов.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи.

## Что вернёт

Возвращает список креативов (смарт-баннеры, HTML5) из библиотеки креативов.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Получить список креативов (смарт-баннеры, HTML5) из библиотеки креативов в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
