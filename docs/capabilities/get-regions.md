# Яндекс Директ: Поиск регионов — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Ищет id регионов для таргетинга (те самые regionIds, которые нужны create_ad_group).

Техническое имя: `get_regions`

## Какую задачу решает

> Я хочу найти регионы для таргетинга.

Ищет id регионов для таргетинга (те самые regionIds, которые нужны create_ad_group).

## Когда использовать

Используйте эту возможность, когда нужен результат «Поиск регионов» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `query` — **необязательно**. Подстрока названия региона без учёта регистра, например 'Москва' или 'Moscow'.
- `limit` — **необязательно**. Максимум регионов в ответе. По умолчанию 50.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.

## Пример запроса

> Найти регионы для таргетинга в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Фильтр — подстрока названия; количество результатов ограничено limit.

Доступ также зависит от прав токена, квот и ограничений исходного API.
