# Яндекс Директ: Создать набор быстрых ссылок — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт набор быстрых ссылок (1–8 штук).

Техническое имя: `create_sitelinks_set`

## Какую задачу решает

> Я хочу создать набор быстрых ссылок.

Создаёт набор быстрых ссылок (1–8 штук).

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать набор быстрых ссылок» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `sitelinks` — **обязательно**. От 1 до 8 быстрых ссылок.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать набор быстрых ссылок в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Наборы неизменяемы — чтобы поменять ссылки, нужно создать новый набор и переназначить его объявлению.

Доступ также зависит от прав токена, квот и ограничений исходного API.
