# Яндекс Директ: Обновить группу объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Обновляет название и/или регионы показа группы объявлений (adgroups/update).

Техническое имя: `update_ad_group`

## Какую задачу решает

> Я хочу обновить группу объявлений.

Обновляет название и/или регионы показа группы объявлений (adgroups/update).

## Когда использовать

Используйте эту возможность, когда нужен результат «Обновить группу объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `id` — **обязательно**. Id группы, которую нужно обновить.
- `name` — **необязательно**. Новое название группы.
- `regionIds` — **необязательно**. Новые id регионов показа.
- `negativeKeywords` — **необязательно**. Заменяет минус-фразы группы; пустой массив очищает их.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Обновить группу объявлений в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Проверьте обязательные параметры, права токена и актуальные ограничения исходного API.

Доступ также зависит от прав токена, квот и ограничений исходного API.
