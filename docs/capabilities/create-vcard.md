# Яндекс Директ: Создать визитку — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Создаёт виртуальную визитку в кампании.

Техническое имя: `create_vcard`

## Какую задачу решает

> Я хочу создать визитку.

Создаёт виртуальную визитку в кампании.

## Когда использовать

Используйте эту возможность, когда нужен результат «Создать визитку» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignId` — **обязательно**. Кампания, к которой относится визитка.
- `country` — **обязательно**. Страна, например Россия.
- `city` — **обязательно**. Город, например Москва.
- `companyName` — **обязательно**. Название организации.
- `workTime` — **обязательно**. Время работы в формате API, например "1#5#9#00#18#00" — пн–пт 09:00–18:00.
- `phone` — **обязательно**. Контактный телефон.
- `street` — **необязательно**. Улица в адресе организации.
- `house` — **необязательно**. Номер дома.
- `building` — **необязательно**. Корпус или строение.
- `apartment` — **необязательно**. Офис, помещение или квартира.
- `contactPerson` — **необязательно**. Имя контактного лица.
- `contactEmail` — **необязательно**. Email контактного лица.
- `extraMessage` — **необязательно**. Дополнительная информация на визитке.
- `ogrn` — **необязательно**. ОГРН.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Создать визитку в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Визитки неизменяемы — чтобы поменять, нужно удалить и создать заново.

Доступ также зависит от прав токена, квот и ограничений исходного API.
