# Яндекс Директ: Список объявлений — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Возвращает список объявлений. Нужно передать campaignIds, adGroupIds или ids — API Яндекс Директа требует хотя бы один из них; states и statuses только сужают выборку. Текстовые объявления Единой перформанс-кампании Директ хранит комбинаторными и отдаёт в одном из двух видов. Без responsiveAdFieldNames — в виде совместимости: Type TEXT_AD, запрошенные тексты в объекте TextAd. Если передано хотя бы одно поле в responsiveAdFieldNames — как Type RESPONSIVE_AD с объектом ResponsiveAd вместо TextAd, где заголовки и тексты — массивы Titles[] и Texts[] со статусом модерации каждого варианта.

Техническое имя: `list_ads`

> Я хочу посмотреть объявлений.

## Когда использовать

Используйте эту возможность, когда нужен результат «Список объявлений» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `campaignIds` — **необязательно**. Фильтр по id кампаний.
- `adGroupIds` — **необязательно**. Фильтр по id групп объявлений.
- `ids` — **необязательно**. Фильтр по id объявлений. Длинный id (приходит в ответах строкой) передавать строкой как есть.
- `states` — **необязательно**. Фильтр по состояниям объявлений.
- `statuses` — **необязательно**. Фильтр по статусам модерации.
- `fieldNames` — **необязательно**. Какие поля объявления вернуть; без параметра — Id, AdGroupId, CampaignId, Status, State, Type. Тексты и ссылки (Title, Title2, Text, Href, …) приходят в объекте TextAd. Если переданы только они, в запрос добавляется Id: API не принимает пустой список полей объявления.
- `responsiveAdFieldNames` — **необязательно**. Поля комбинаторного объявления (ResponsiveAdFieldNames API, передаются как есть). Хотя бы одно поле переключает ответ для комбинаторных объявлений на Type RESPONSIVE_AD с объектом ResponsiveAd вместо TextAd. Цены в PriceExtension (Price, OldPrice) приходят как в API — в микроединицах (× 1 000 000) валюты PriceCurrency, без пересчёта.
- `limit` — **необязательно**. Максимум объектов на страницу.
- `offset` — **необязательно**. Смещение постраничной выдачи (сколько объектов пропустить).
- `autoPaginate` — **необязательно**. Забрать все страницы, идя по LimitedBy (limit тогда не ограничивает общий объём).

## Что изменится в Яндекс Директе

Инструмент только читает данные или состояние подключения и не изменяет их.
