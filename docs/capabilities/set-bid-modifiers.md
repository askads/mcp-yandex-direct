# Яндекс Директ: Изменить корректировки ставок — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Меняет процент существующих корректировок (bidmodifiers/set) по id корректировки.

Техническое имя: `set_bid_modifiers`

## Какую задачу решает

> Я хочу изменить корректировки ставок.

Меняет процент существующих корректировок (bidmodifiers/set) по id корректировки.

## Когда использовать

Используйте эту возможность, когда нужен результат «Изменить корректировки ставок» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `bids` — **обязательно**. В каждом элементе нужны id и percent.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Изменить корректировки ставок в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

BidModifierSetItem принимает только Id и BidModifier; включить/выключить корректировку через API нельзя (метод bidmodifiers/toggle устарел и не поддерживается) — чтобы отключить корректировку, удалить её через delete_bid_modifiers.

Доступ также зависит от прав токена, квот и ограничений исходного API.
