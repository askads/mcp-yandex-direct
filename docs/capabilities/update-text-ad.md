# Яндекс Директ: Обновить текстовое объявление — MCP-инструмент (tool)

**MCP-инструмент (tool) для Яндекс Директа:** Обновляет заголовок, текст или посадочную страницу текстового объявления (ads/update).

Техническое имя: `update_text_ad`

## Какую задачу решает

> Я хочу обновить текстовое объявление.

Обновляет заголовок, текст или посадочную страницу текстового объявления (ads/update).

## Когда использовать

Используйте эту возможность, когда нужен результат «Обновить текстовое объявление» без ручной работы в интерфейсе Яндекс Директа. Операция выполняется только по вызову из AI-приложения.

## Что нужно передать

- `id` — **обязательно**. Id объявления, которое нужно обновить.
- `title` — **необязательно**. Новый заголовок (Title 1), до 56 символов.
- `title2` — **необязательно**. Новый второй заголовок (Title 2), до 30 символов.
- `text` — **необязательно**. Новый текст объявления, до 81 символа.
- `href` — **необязательно**. Новый URL посадочной страницы.

## Что вернёт

Возвращает компактный JSON-ответ исходного API или понятную ошибку MCP-инструмента. Точный состав полей зависит от операции и описан в техническом справочнике.

## Что изменится в Яндекс Директе

Инструмент изменяет реальные данные Яндекс Директа так, как описано выше. Автоматического отката сервер не обещает.

## Пример запроса

> Обновить текстовое объявление в Яндекс Директе. Если не хватает обязательных идентификаторов, сначала уточни их.

## Возможные ошибки и ограничения

Правка активного объявления отправляет его на повторную модерацию.

Доступ также зависит от прав токена, квот и ограничений исходного API.
